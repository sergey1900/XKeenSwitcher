# 🚀 XKeenSwitcher v2.0.1

Крупное обновление веб-панели управления для **XKeen (Xray / sing-box)** на роутерах с **Entware** (Keenetic, OpenWrt и др.). 

Версия **v2.0.1** полностью переосмысливает архитектуру приложения, разделяя серверы и маршрутизацию на независимые модули, добавляя автоматическую отказоустойчивость (Failover), измерение задержки (Ping), импорт по ссылкам, генерацию QR-кодов и механизм встроенного автообновления прямо из веб-интерфейса в 1 клик.

---

### 🌟 Все новые возможности (отличия от v1.0.0):

#### 1. 🔄 Встроенное автообновление в 1 клик (In-App Auto-Update)
- **Проверка релизов на лету:** Панель автоматически опрашивает GitHub Releases API и сообщает о выходе новой версии.
- **Кнопка «Обновить» в футере:** При обнаружении новой версии рядом с бейджем появляется кнопка обновления.
- **Интерактивное модальное окно:** Пошаговый 4-этапный мастер с отображением статуса:
  1. *Бэкап данных:* Автоматическое сохранение `data/profiles.json` перед обновлением.
  2. *Загрузка:* Скачивание архива новой версии с GitHub через curl или Node.js HTTPS.
  3. *Безопасная распаковка:* Замена файлов приложения с абсолютной защитой пользовательских настроек и профилей (`data/` не затрагивается).
  4. *Перезапуск:* Автоматический перезапуск системной службы `/opt/etc/init.d/S99xkeen-switcher restart` и перезагрузка вкладки браузера после восстановления готовности сервера.

#### 2. 🔀 Модульная архитектура: разделение Подключений и Роутингов
- **В v1.0.0** профили были монолитными (outbound + routing в одном файле/объекте).
- **В v2.0.1** подключения (Outbounds / Серверы) и таблицы маршрутизации (Routings) разделены на независимые сущности:
  - Любой роутинг можно на лету привязать к любому подключению прямо из карточки сервера.
  - **Системные защищенные пресеты:**
    - 🛡️ *«Всё через VPN»* — полный туннель всего интернет-трафика.
    - 🇷🇺 *«Всё через VPN кроме РФ»* — весь трафик направляется через VPN, а российские домены/IP, сервисы, банки и Госуслуги идут напрямую.
  - **Пользовательские роутинги:** Создание, клонирование, ручное редактирование и удаление собственных гибких правил маршрутизации.

#### 3. 🛡️ Отказоустойчивость (Failover & Auto-Failover)
- **Фоновый мониторинг доступности:** Панель периодически тестирует доступность внешних контрольных сайтов (через туннель) и незаблокированных ресурсов.
- **Стратегии автоматического переключения при аварии:**
  - Переключение на заданный резервный узел (Backup Server).
  - Выбор лучшего сервера из пула по минимальному пингу (*Lowest Ping*).
  - Циклический перебор активных серверов (*Round-Robin*).
- **Автовозврат (Failback):** Автоматическое возвращение на основной сервер после восстановления его работоспособности.
- **Журнал событий (Failover History):** Полный лог инцидентов с датами, задержками и причинами переключений.

#### 4. ⚡ Измерение задержки серверов (Ping / RTT)
- Проверка задержки до конкретного сервера в один клик.
- Кнопка **«Проверить пинг всех»** для одновременного замера отклика всей базы подключений.
- Наглядная цветовая индикация качества соединения (зеленый / желтый / красный) и точное время отклика в мс.

#### 5. 🔗 Импорт ссылок и генерация QR-кодов
- **Умный парсер Share-ссылок:** Добавление подключений простой вставкой ссылок `vless://`, `vmess://`, `ss://`, `trojan://` — панель сама извлекает адреса, порты, UUID/пароли, настройки TLS, Reality, SNI, Flow, WebSocket, gRPC и формирует валидный `05_outbounds.json`.
- **QR-коды и экспорт:** Генерация QR-кода и ссылки прямо в карточке любого подключения для мгновенной настройки мобильных устройств (v2rayNG, Streisand, Shadowrocket, Sing-box, FoXray).

#### 6. 🌍 Определение стран и флаги (GeoIP & Twemoji)
- Автоматическое определение страны расположения сервера по домену или IP-адресу.
- Встроенный автономный шрифт `TwemojiCountryFlags.woff2` гарантирует красивое отображение флагов стран на любых устройствах и ОС (включая Windows, Android, iOS, macOS).

#### 7. 💾 Резервное копирование и восстановление (Backup & Restore)
- Полный экспорт базы (все подключения, модульные роутинги, история и настройки отказоустойчивости) в один JSON-файл.
- Восстановление из бэкапа с опциями слияния (дополнение существующей базы) или полной замены.

#### 8. 📝 Продвинутый редактор конфигураций
- Встроенный редактор с подсветкой, автоформатированием JSON и поддержкой комментариев (`//` и `/* */`).
- Проверка синтаксиса перед сохранением для предотвращения падения службы XKeen/Xray.

#### 9. 🛠️ Улучшенные скрипты установки и удаленная служба
- Скрипт `install.sh` автоматически диагностирует Entware, доустанавливает недостающие пакеты (`node`, `curl`, `tar`, `ca-certificates`), подхватывает существующие конфиги роутера и настраивает фоновый демон `/opt/etc/init.d/S99xkeen-switcher`.
- Скрипт `uninstall.sh` обеспечивает чистое удаление службы и файлов панели.

### 📥 Установка и обновление

- **Обновление существующей панели:**
  Нажмите появившуюся кнопку **«Обновить»** в футере веб-интерфейса.
- **Чистая установка в Entware (одна команда через SSH):**
  ```bash
  curl -sL https://raw.githubusercontent.com/sergey1900/XKeenSwitcher/main/install.sh | sh
  ```

Панель доступна по адресу: `http://192.168.1.1:3000` (или IP вашего роутера).
